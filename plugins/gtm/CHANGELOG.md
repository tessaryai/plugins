# gtm plugin (Tessary GTM) changelog

This file covers the directory edition. The full edition, Tessary GTM Pro, has its own changelog in `plugins/gtm-pro/CHANGELOG.md`. Releases up to v0.2.1 were the full plugin under the name `gtm`.

> **TL;DR (v0.3.0, current: first directory edition. gtm is now Tessary GTM, with no scripts. It runs through connectors only in Claude Code and Cowork, and points to Tessary GTM Pro at its limits.)**
> What it is: the plugin is generated from Tessary GTM Pro without its helper scripts, so it holds only Markdown, JSON and an image. Every skill takes the connectors-only path and reads and writes its config with Claude's file tools. Notion is read in view mode through the Notion connector. Commands are `/gtm:<skill>`. Limits: the funnel counts by hand up to about 150 counted contacts, with a second independent count from the saved export that must match cell by cell, else BLOCKED. Imports take a CSV of about 200 rows or fewer, or a HubSpot, Pipedrive or Attio connector import of the same size; the row count is checked before the run folder is made. The CRM should stay under about 300 contacts for reliable view-mode reads. Tools that would need an API key (Gojiberry, lemlist, Instantly, Hunter, and Fathom, Fireflies, HubSpot and Pipedrive without a connector) are blocked. Upgrade path: at each of these four limits (a large CRM or the Notion query quota, a big import or a CRM without a connector, an API-key tool without a connector, a large funnel) the skills show one message, once per run: install Tessary GTM Pro with `/plugin marketplace add tessaryai/plugins` and `/plugin install gtm-pro@tessary` in Claude Code. In Cowork, Pro needs Claude Code. Both editions read the same config folder and format, so a switch keeps every setting, cursor and log. Users of `gtm@tessary` 0.2.1: this update removes the scripts; install `gtm-pro@tessary` to keep them. Tested end to end without Python against a test Notion workspace: setup, a CSV import (and the 200-row stop), a sweep, a campaign-run dry run and a funnel publish. Not tested: a CRM over 300 contacts, a funnel over 150 counted contacts, and any live send. If you pin the marketplace `ref`, use `gtm-v0.3.0`.
